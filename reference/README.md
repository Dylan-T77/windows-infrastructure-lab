# Technical Reference

A practical command reference for the infrastructure lab and general system administration.

The reference is intentionally command-focused. It is a quick lookup rather than a replacement for project documentation.

## Sections

- [Linux Commands](linux-commands.md)
- [Windows Commands](windows-commands.md)
- [PowerShell Commands](powershell-commands.md)

## Reference Principles

- Prefer commands that are safe for inspection and troubleshooting.
- Clearly label commands that change configuration.
- Avoid storing passwords, API keys, tokens, private keys or other secrets in this repository.
- Add useful commands discovered during the lab as the project develops.
