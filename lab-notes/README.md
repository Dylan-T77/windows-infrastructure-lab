# Lab Notes

A chronological record of the Windows Infrastructure Lab.

## Purpose

Use this area for observations made while actually working on the virtual machines. Keep implementation notes separate from polished documentation.

## Suggested Structure

```text
lab-notes/
├── README.md
├── build-log.md
├── dc01.md
├── client01.md
└── issues/
```

## Build Log

Record major changes in chronological order:

- Date/time
- Host affected
- Change made
- Reason
- Verification
- Result

## Rule

Do not claim a component is operational until it has been tested on the actual lab environment.

Never store passwords, recovery codes, API tokens, private keys or other secrets in lab notes.
