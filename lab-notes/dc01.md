# DC01 Lab Notes

Working notes for the Windows Server domain controller.

## Current State

- Hostname: `DC01`
- Operating system: Windows Server 2022
- Role: Domain Controller / Active Directory / DNS
- Domain: `corp.lab`
- IPv4 address: `192.168.122.10`
- Virtual network: `192.168.122.0/24`

## Configuration Log

### Network

- VirtIO Ethernet adapter installed and active.
- Static IPv4 address configured as `192.168.122.10`.
- Connectivity to the virtual gateway was verified.

### Active Directory

- Active Directory Domain Services installed.
- DC01 promoted as the first domain controller for `corp.lab`.
- Active Directory Users and Computers verified.
- Custom OUs created for `Admins`, `Groups`, `Servers` and `Workstations`.
- Security groups created: `IT-Admins`, `IT-Users`, `HR-Users`.
- Test users created and assigned to their corresponding security groups.

### DNS

- Forward DNS zone `corp.lab` verified.
- Reverse DNS zone `122.168.192.in-addr.arpa` configured.
- Reverse lookup for `192.168.122.10` verified successfully as `dc01.corp.lab`.

### Group Policy

- GPO `Workstation Baseline` created.
- GPO linked to the `Workstations` OU.
- Windows Defender Firewall configured in the Domain Profile of the baseline GPO.
